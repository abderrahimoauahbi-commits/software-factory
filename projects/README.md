# projects

**Statut : réservé (Playbook §16.1).** Aucun contenu de projet n'est rangé ici.

Les projets sont des **instances** de la Factory (Executable Schemas §1) : leur carte d'enregistrement et,
tant que le projet ne l'a pas adopté, le brouillon de leur manifest vivent dans `registry/projects/<id>/`.
Le manifest définitif vit dans le dépôt du projet (ADR-0001). Correction F-03 de l'ADR-0002.
